# 普通摄像头适配器

由 camera 节点调用，使用 `v4l` 访问 Linux V4L2，不启动额外服务。

- `discover()`：枚举实际设备、名称、稳定标识、像素格式、分辨率和帧率。离散配置完整列出；连续/步进配置目前列出范围两端，未实现任意值编辑。
- `Stream::open()`：按稳定标识重新解析设备节点，设置并核对驱动实际接受的格式与帧率。
- `next_frame()`：读取原生帧，使用 OpenCV 解码/转换为统一 `rgb8`，带来源、设备帧序号和主机接收时间输出。不生成深度、内参或外参。无法解码或模式切换后尚未匹配新尺寸的帧返回待采集，不发布坏帧或旧图；持续无有效图像按现有采集超时报告原始原因。

支持 MJPG/JPEG、YUYV、UYVY、RGB3、BGR3、GREY、NV12；其他枚举格式显示不可用。标识优先使用 by-id，其次 by-path/总线端口；无唯一序列号的设备换插口后需重新绑定。

`by-id` 由系统 udev 提供，不保证厂商提供了唯一序列号。多个同型号、无唯一序列号的设备可能共享同名链接；重插后需核对角色对应的实际画面，不能将该类设备的跨端口身份稳定性视为已验证。

RGB/BGR 与行填充测试：在 camera 构建环境执行 `cargo test -p uvc-camera`，不要在主机另装 OpenCV。实体设备验收从网页选择来源和流配置、保存、确认实时图像，随后拔插检查断流提示与重新保存恢复；单元测试不替代硬件验收。
