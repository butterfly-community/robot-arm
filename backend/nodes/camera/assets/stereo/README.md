# 四路双目测试画面

来源：本项目 ChArUco 板、正式机械臂 URDF，以及 OpenCV 投影生成器。
生成与独立检查代码在独立 tools 仓库的 `perception/generate-stereo-assets.py`、
`perception/check-stereo-assets.py`；生产构建直接使用本目录，不依赖 tools 或 temp。

- 四个明确的文件输入：外部左/右、腕部左/右，不自动替代掉线摄像头。
- 原生 1920×1080；1280×720 由同一图像等比例采样。
- 文件源以 10 FPS 重放选定画面，用于几何与业务链路测试，不代表真实 USB 相机帧率或带宽。
- `scene`：带纹理桌面 Z=0.55 m、紫色前景表面 Z=0.50 m（平面深度靶，不是完整抓放场景）。
- `board-01`～`board-24`：同编号左右图对应同一块 75 mm ChArUco 板。
- `handeye-01`～`handeye-12`：按 `truth.json` 中关节角和正式 TCP 正运动学生成的外参图像。
  外部板随工具移动；腕部板固定，相机随工具移动。
- 测试支架基线为外部 80 mm、腕部 60 mm，仅定义资产，不约束真实设备。

`manifest.json` 只向驱动提供图像文件、尺寸和标签。`truth.json`、`*-truth-depth.png`
仅用于测试断言，生产标定和深度计算不读取它们。测试不使用预解内参、外参或预制深度作为结果。
文件采集的时间戳检验软件配对流程，不能证明真实 USB 相机的曝光同步。
