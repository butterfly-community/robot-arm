# 计算服务增量补丁

`graspgenx-knn.patch` 针对基础镜像固定的 GraspGenX
`b9429097728cb1c430dd78b92edf17ba318aad03`，由本服务 Dockerfile 应用并复制到运行镜像。
不要求重编基础镜像；升级依赖时必须重新核对补丁和测试，不能静默跳过应用失败。

2026-09-09 真机网页自动分割后，计算容器退出 137、`OOMKilled=true`。上游目标点云去噪
在 `knn_points` 创建 `torch.cdist(X, X)` 和同尺寸自邻点掩膜，内存随点数平方增长；
十万点的 float32 距离矩阵本身即约 40 GB，尚未计自邻点掩膜和其他模型内存。

补丁用 SciPy `cKDTree.query(eps=0)` 求精确近邻，保持原距离度量（正式去噪使用 L1）、
20 个非自身邻点、平均距离和 0.014 阈值；不减少输入点、不裁剪候选、不改变环境碰撞。
只排除自身索引，重复坐标仍为合法邻点。距离在原张量 dtype/device 上重新计算。
等距邻点的索引顺序可能不同；原去噪只使用距离均值。浮点结果按容差对照，不声称位级相同。

在新构建的服务运行镜像运行 `tests/test_grasp_knn.py`：小点云对照原 `torch.cdist`、
重复点/自身排除、原去噪掩膜，以及十万点且禁止调用 `torch.cdist` 的回归。
测试入口和全部回归命令见仓库 `tools/diagnostics/README.md`。
