## 抓放现状与验收边界

原始主线“实际物体抓起、运输并释放”已由用户验收。MTC 当前仍使用原生 C++，
职责拆分为任务工厂、场景管理、候选排序与 Action 调度；调用链和配置见
[架构文档](BACKEND.md#mtc-模块边界)及[参数审计](BACKEND.md#抓放参数审计2026-09-14)。
不在此重复易失同步的参数数值和每轮耗时。

[既有五轮记录](../tools/diagnostics/evidence/2026-09-14-collision-approach-five/README.md)
属于移除接近段物体高度上限及应用层八个 IK 截断后的历史版本，不能视为后来代码修改的验收结果。
这些记录只证明对应物体、摆放和版本的实物夹持、运输与释放，
不证明自动分割识别率、任意物体可靠性、冷启动性能或精确放置能力。

软件成功、attach 或 IK 成功不能单独证明抓取成功；后续复测仍须从真实网页观察实物全过程。
性能优化不重新引入历史的 5 s / 30 s 待办；不把历史测试结果写成当前重新测得的成绩。

  不宣称所有维护指令都经过破坏性实测，也不把即时读回当成重新上电验证。
- 标定用同张图像之后的实际电机反馈计算 FK，不使用命令角度或裁剪后的规划状态。
  九组求解后回工作位，匹配回位成功才允许确认应用。
- D415 USB 3.2 已验收九组标定、回位、网页保存和刷新通过；当轮 RMS / 最大拟合残差

## 网页与分割

- 五页桌面/窄屏、栏目间距、折叠保持、草稿与已生效值、标定回显和异步进度均有浏览器回归。
- 实际相机同帧手动、提示词、自动分割可独立/组合使用；统一显示原图、带来源框与标题详情。
  手动矩形不是模型精细分割，不能把其 confidence 当成识别成功率。
- 分割、三维定位、选中对象候选各自独立；启动复用当前结果，不隐式重拍。
  AI 只增加解析/选择，之后与手动按钮共用 `startPickPlace`，不维护第二条提交实现。
- 本轮清除旧 `overlay.png` 生成与活跃消费者，保留冻结原图及 mask；历史证据中的同名图片不改写。
- 分割完成不再覆盖整个资源表、删除深度预览；预览按钮沿用已有首帧就绪条件，不再提前提交空图请求。
- 拦截请求的浏览器故障/布局回归只证明 UI 行为；真实业务验收须记录未拦截的正式服务响应，
  不能替代真机夹持证据。未重新测试的外部 AI 供应商可用性不作保证。

## 使用边界

海绵通过不保证硬盒、透明物体、反光表面和任意布局都可靠，不把滑脱全部归因于夹爪形态。
夹持反馈是功率推导的负载百分比，不是牛顿力；允许正常波动，放置不承诺精确居中。
环境是任务点云快照，不持续感知动态障碍；相机与电机采样是软件配对，不是硬件同步。
这些是已知边界，不是待办。真机精度限制见 [型号说明](STARARM-102.md)。

## 测试资产

唯一参数源为 [相机资产目录](../backend/nodes/camera/assets)。RGB、深度、点云模拟同一相机视角，
包含方块、篮子和地面，不包含机械臂；ChArUco 板只在标定阶段出现。

| 项目 | 定义 |
| --- | --- |
| 坐标 | 基座原点；+X 正前方，用户在 -X 侧，相机在物体 +X 侧朝用户看 |
| 物体中心横线 | X=187.5 mm，距底座前缘 X=37.5 mm 的横线 150 mm |
| 方块 | 30×30×30 mm，中心 (187.5,65,15) mm，底面 Z=0 |
| 篮子 | 主体 100×100×50 mm，中心 XY=(187.5,-115) mm，底面 Z=0 |
| 壁、底、沿 | 厚 5 mm；沿外伸 15 mm，含沿占地 130×130 mm |
| 空隙 | 100 mm，中线 Y=0；大小不同的两个物体中心不以 Y=0 等距 |
| 相机 | 光心 (300,0,550) mm，朝 (100,0,150) mm；Y=0，向 -X 俯视 |
| RGB-D | 1920×1080 / 1280×720；RGB 与已对齐深度同坐标系，Z16 表示光轴 Z |

测试提示词 `red cube` / `dark rectangle` 仅用于匹配测试图，不是生产固定类别。
理想模拟资产按 ≤1 mm 验收；Z16 的 1 mm 编码单位另有半单位取整误差。
模拟不包含 RealSense 立体匹配、真实噪声或物体接触动力学；可见点包围盒不是完整材料体积。
