# 验收状态与测试资产

这里只维护已完成的验收范围、当前使用边界和复测入口，不维护排查流水账或中间状态。
现场证据位于 `tools/diagnostics/evidence/`，历史实现从 Git 恢复；旧批次不代表当前版本的全部能力。

## 舵机驱动验收

当前串口事务串行，异步只用于不阻塞事件循环：Monitor、参数读取和维护事务占用同一总线，
普通位置命令在事务完成后发送。等待时只保留最新完整目标，不积压历史轨迹点；断连清除待发目标。
这项修复没有改变角度、零点、速度、夹持目标、回读周期或超时。实现见
[执行调用链](BACKEND.md#stararm-102-execution-node)。

2026-09-13 验收范围：

- 驱动库 27 项测试重复 10 轮，覆盖协议分片、校验、错误应答、事务互斥及重复压力测试；执行适配层 32 项测试通过。
- 独立真实总线测试 3 轮：21 次 Ping、300 次七舵机 Monitor、567 项公开寄存器读取通过。
  Monitor 中位约 5.34 ms、P95 约 5.4 ms；测试间隔 200 ms，不是生产反馈配置。
- 网页完整参数读取 3 轮通过；J1 软启动时间 3000→3001→3000 ms 的写入、即时回读和恢复重复 3 轮通过。
- 修复后追踪中 1,100 次运动写入未插入未完成的回读事务，查询均完整结束；随后两轮不启用追踪的标定通过。

驱动库测试是独立流程，不能用业务成功代替。协议与 PTY 测试不等于所有指令真机验收；
出厂复位、ID、波特率、原点等未做破坏性实测。参数即时回读不等于重新上电后的持久性或行为验证，
软件服务重启也不等于舵机重新上电。没有独立高频测量，不宣称机械振动为零。

复现方法与原始数据见 [驱动测试](../backend/crates/fashionstar-uart/README.md#测试与复现)、
[现场证据](../tools/diagnostics/evidence/2026-09-13-servo-driver/README.md)。

## 标定与配置持久化

真机标定使用图像同次采样的实际电机反馈计算 TCP，不用命令角度或旧反馈填充。
九组采样后自动回工作位，匹配回位成功状态后才进入确认应用；串口断连明确报错，保留之前已保存的外参。
流程、姿态和精度限制见 [型号文档](STARARM-102.md)。

驱动修复后的三轮真机标定均完成采样、回位与网页应用：

| 轮次 | RMS / 最大拟合残差 mm |
| --- | --- |
| 1 | 4.211 / 6.655 |
| 2 | 4.799 / 7.630 |
| 3 | 4.283 / 6.905 |

上述数值是当次拟合结果，不是独立空间绝对精度。整套重启后，经网页启用保存的相机配置，
第三轮外参逐字段保持一致，已标定状态、重新标定入口与实时图像均已核对。
相机重启后默认未选择，不表示配置或标定丢失；选择原设备后复用保存结果，无须重新标定。
参数与外参保存在 `backend/config/runtime/`，不依赖 `temp/`。

用户升级 D415 USB 连接后重新标定，驱动报告 USB 3.2；九组真实反馈采样、自动回位、网页保存和
刷新复核均通过，RMS / 最大残差为 **5.330 / 7.570 mm**。见
[USB 3 本轮记录](../tools/diagnostics/evidence/2026-09-13-usb3-calibration/README.md)。

- [20° 五次实测](../tools/diagnostics/evidence/2026-09-12-fingertips-20/README.md)：五次正常网页海绵抓取通过，
  包含人工重新摆位与提示调整，不是无人干预或精确放置验收。

海绵通过不保证硬盒、透明物体或任意布局都可靠，也不把滑脱全部归因于夹爪形态。

环境采用任务点云快照，不持续感知动态障碍。此前约 30 秒的全链路耗时期望尚未达到。
这些是使用边界，不重新列为项目未完成任务。真机精度限制统一见 [型号文档](STARARM-102.md)。

## 测试资产

唯一参数源为 [相机资产目录](../backend/nodes/camera/assets)。RGB、深度、点云模拟同一相机视角，
包含方块、篮子和地面，不包含机械臂；ChArUco 板只在标定阶段出现。

| 项目 | 定义 |
| --- | --- |
| 坐标 | 基座原点；+X 正前方，用户在 -X 侧，相机在物体 +X 侧朝用户看 |
| 物体中心横线 | X=187.5 mm，距底座前缘 X=37.5 mm 的横线 150 mm |
| 方块 | 30×30×30 mm，中心 (187.5,65,15) mm，底面 Z=0 |
| 篮子 | 主体 100×100×50 mm，中心 XY=(187.5,-115) mm，底面 Z=0 |
| 壁、底、沿 | 厚 5 mm；沿外伸 15 mm，含沿占地 130×130 mm |
| 空隙 | 100 mm，中线 Y=0；大小不同的两个物体中心不以 Y=0 等距 |
| 相机 | 光心 (300,0,550) mm，朝 (100,0,150) mm；Y=0，向 -X 俯视 |
| RGB-D | 1920×1080 / 1280×720；RGB 与已对齐深度同坐标系，Z16 表示光轴 Z |

测试提示词 `red cube` / `dark rectangle` 仅用于匹配测试图，不是生产固定类别。
理想模拟资产按 ≤1 mm 验收；Z16 的 1 mm 编码单位另有半单位取整误差。
模拟不包含 RealSense 立体匹配、真实噪声或物体接触动力学；可见点包围盒不是完整材料体积。
