## 当前测试资产

唯一参数源：[camera 资产目录](../backend/nodes/camera/assets)中的几何配置及生成结果。
当前匹配提示词为 `red cube` / `dark rectangle`，用于定位测试图，不是生产固定类别；
后者可能匹配内区和沿，不能要求恰好一个放置区域。

| 项目 | 定义 |
| --- | --- |
| 坐标 | 基座原点；+X 正前方，用户在 -X 侧，相机在物体 +X 侧朝用户方向看 |
| 底座前缘横线 | X=37.5 mm，来自补丁 URDF 的底座网格边界 |
| 两物体中心横线 | X=187.5 mm，与底座前缘平行，线距 150 mm |
| 方块 | 30×30×30 mm，中心 (187.5,65,15) mm；底面 Z=0 |
| 篮子 | 主体 100×100×50 mm，中心 XY=(187.5,-115) mm；底面 Z=0 |
| 壁、底、沿 | 厚 5 mm；四边沿外伸 15 mm；含沿占地 130×130 mm |
| 空隙 | 方块相邻边 Y=+50 mm，篮沿相邻边 Y=-50 mm；空隙 100 mm，中线 Y=0 |
| 中心间距 | 180 mm；物体大小不同，两个中心不以 Y=0 等距，空隙才对称 |
| 相机 | 光心 (300,0,550) mm，朝 (100,0,150) mm；Y=0，向 -X 俯视；预置真值，不是实测外参 |
| RGB-D | 理想 RGB 与已对齐深度，同一彩色光学坐标系；Z16 是光轴 Z，不是离地高度或欧氏距离 |

已核验范围：

- 1920×1080、1280×720 各五轮重复生成及五视角验证；源 PNG 摘要匹配，深度与实例真值重复生成逐字节一致。
- 量化前地面深度最大误差分别 0.001113 / 0.001341 mm；
  Z16 取整最大误差分别 0.499750 / 0.499112 mm。1 mm 深度单位的量化不是标定误差。
- 逐像素反投影点云含地面，保留单视角遮挡空洞，不填充实体背面。
  相机视角中篮子在左、方块在右；不拿机械臂侧旁观图当相机图。
- 整臂叠加使用原始 URDF 米制网格；相机图标和内参视锥仅用于布局展示，
  二者不进入正式 RGB-D 或点云。
- 网页原生 RGB、归一化深度曾与正式源图逐像素一致，标定结束后无板残留；
  此项不等同于原始运行态 Z16 字节传输核验。

## 已归档的模拟标定

以下三轮、27 个样本来自正式相机 → 运动 → 软件反馈 → 检测/手眼求解 → 应用外参链路，
不是用预置外参冒充求解。原始会话链接在下节。

| 轮次 | 外参平移误差 mm | 最大全场景点位移 mm | 最大观测板面点误差 mm | ≤0.1 mm |
| --- | ---: | ---: | ---: | --- |
| 1920 第一轮 | 0.017362 | 0.039810 | 0.014009 | 通过 |
| 1280 第一轮 | 0.015518 | 0.061109 | 0.026906 | 通过 |
| 1920 第二轮 | 0.017362 | 0.039810 | 0.014009 | 通过 |

- 每轮九姿态、每图 16 个 ChArUco 内角点匹配；不等于板外边缘全部入镜。
  九姿态来自型号声明，不能当成真机已确认姿态。
- FK 对照：最大位置差约 1.34×10⁻¹³ mm、旋转差约 3.52×10⁻¹⁴°，验证软件链路解释一致。
- 同一 Z16 下逐点计算外参影响，覆盖 2073600 / 921600 个有效点；
  板面检查覆盖整个 75 mm 板，不只检查原点。
- 方块/筐可见点云 AABB 各轴尺寸变化最大 0.004450 mm；刚体体积比为 1。
  AABB 随旋转变化不是材料体积变化，不能把可见表面包围体当实心实体。
- 1920 两轮一致来自确定性渲染/反馈；1280 走正式缩放路径。2026-09-06 重算三份会话仍一致。
- 局部精修使用 OpenCV `cornerSubPix`，7 px 窗口来自同图对照；1280 对照最大偏差由
  0.158934 mm 降至 0.061042 mm，同时调整了窗口、终止精度及零区，不能只归因于一个参数。
  超采样 8→16 无收益已撤回。独立测试含约 34° 倾角、15° 板面内旋转和三轮扰动，未放宽断言。

归档最终最大误差 **0.061109 mm**。这是理想模拟精度，不是 RealSense/舵机的精度承诺；
本模拟源不包含左右目立体匹配，不能声称验证了立体视差。
2026-09-07 全仓库复测再次跑完三轮正式标定，结果范围与测试计数统一见
[审查报告](investigations/repository-audit.md)，不把旧表冒充新一轮原始数据。

## 抓取修复的有效结论

[穿地排查记录](investigations/stararm-102-grasp-ground.md)保存因果、资产摘要和历史 20 轮证据。
修复采样参考深度后撤销地面下移，刚性地面恢复 Z=0；完整闭合扫掠最低离地 2.740551 mm，
独立 FK 与执行反馈最大位置偏差 0.011592 mm。它们证明该批软件运动及穿地修复，不证明摩擦夹持。

现行约定：使用官方场景筛选，不做人为 top-only 限制；真实 TCP 不变；
释放只指定位置，TCP 离地至少 100 mm，再回工作位。
MoveIt 检测自身和地面，不含筐壁；不能承诺自动避开筐壁。
旧 3/5 mm 地面容许量、旧布局和旧释放增量仅属于历史试验，不是当前配置。
