## 测试资产

唯一参数源为 [相机资产目录](../backend/nodes/camera/assets)。RGB、深度、点云模拟同一相机视角，
包含方块、篮子和地面，不包含机械臂；ChArUco 板只在标定阶段出现。

| 项目 | 定义 |
| --- | --- |
| 坐标 | 基座原点；+X 正前方，用户在 -X 侧，相机在物体 +X 侧朝用户看 |
| 物体中心横线 | X=187.5 mm，距底座前缘 X=37.5 mm 的横线 150 mm |
| 方块 | 30×30×30 mm，中心 (187.5,65,15) mm，底面 Z=0 |
| 篮子 | 主体 100×100×50 mm，中心 XY=(187.5,-115) mm，底面 Z=0 |
| 壁、底、沿 | 厚 5 mm；沿外伸 15 mm，含沿占地 130×130 mm |
| 空隙 | 100 mm，中线 Y=0；大小不同的两个物体中心不以 Y=0 等距 |
| 相机 | 光心 (300,0,550) mm，朝 (100,0,150) mm；Y=0，向 -X 俯视 |
| RGB-D | 1920×1080 / 1280×720；RGB 与已对齐深度同坐标系，Z16 表示光轴 Z |

测试提示词 `red cube` / `dark rectangle` 仅用于匹配测试图，不是生产固定类别。
理想模拟资产按 ≤1 mm 验收；Z16 的 1 mm 编码单位另有半单位取整误差。
模拟不包含 RealSense 立体匹配、真实噪声或物体接触动力学；可见点包围盒不是完整材料体积。

## 维护与复测

网页审查覆盖五个业务页面，而非只验 API。当前编辑策略：未编辑字段跟随服务快照，未保存字段
保留为草稿，服务回显保存结果后释放草稿；明确提供恢复入口。感知页有修改时“保存并运行感知”
先保存再调用原有运行请求，保存失败不运行，不另设推理路径。空间数值离焦保存，失败保留输入。
相机配置和运动覆盖参数的恢复按钮仅撤销网页编辑；“重置当前相机”仍会删除对应持久配置和标定。
标定识别图在本轮样本存在时可展开查看，深度预览可在卡片上单独更新，不触发模型或机械臂动作。
样式只使用当前定义的变量；已移除迁移遗留的无效间距、颜色变量。变量回归和浏览器实际矩形间距
同时检查，避免 CSS 声明存在但没有生效，造成输入框与按钮贴边。

- [测试入口](../tests/README.md)：单元、集成与前端回归。
- [感知工具](../tools/perception/README.md)：生成 RGB-D、标定板和多视角点云审计。
- [诊断工具](../tools/diagnostics/README.md)：采样、标定、MTC 与反馈检查。
- [夹爪工具](../tools/graspgenx/README.md)：真实尺度整臂图、六图与几何复核。

规划成功或软件 attach 不单独证明实物夹稳；环境使用任务点云快照，不持续感知动态障碍；
夹持负载百分比不是牛顿力。以上是使用边界，不是重新开启验收的条件。

文档只维护当前结论和复测方法。逐轮报告、录像、日志和派生图默认写 `temp/`，不再随代码归档；
需要追溯旧调查时从 Git 基线 `a37d8c0` 恢复。正式标定和设备配置仍在
