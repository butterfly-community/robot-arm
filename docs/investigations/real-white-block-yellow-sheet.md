## 已定位的问题

1. 连续量化深度的 Otsu 阈值可能为 0，导致平坦斜面被拆成等深窄条。
   实际请求框内 15,600 有效像素，旧目标仅 675 点。阈值下限取一个 Z16 刻度，保留原始深度；
   不是设置任意毫米门限。回归测试保留背景断层隔离。
2. 文字提示未稳定检出白色物体。改用同一 YOLOE 的官方参考图视觉提示，正式保存参考 RGB 和框，
   在新帧运行模型获得分割，不将框或手填尺寸直接变成场景。文本配置仍由同一请求选择，保存文本
   会清除视觉提示；没有第二个推理服务。默认模型置信度未修改。
3. 参考图请求被 nginx 的默认请求体限制拒绝（413）。只对已有感知请求路由取消 nginx/Axum
   请求体限制，其他 API 不变。部署后视觉感知正式完成。
4. 真实点云包含机器人自身。两次正式任务在 `allow object support contact` 阶段报
   `<octomap> colliding with base_link`，**没有执行运动**。保存实际 PointCloud2 和 PlanningScene，
   隔离原生查询发现底座、link3/4/5/6、左右夹指分别与体素表面重叠，深度约 0.06～0.93 mm。
   初始 self-filter padding 为半个 5 mm 体素，即 2.5 mm。

## 自身点云过滤对照（仍在执行）

保持原始点云、实际关节状态、场景 ACM、目标和地面几何不变，只在隔离域重建官方 Octomap。
8.660254 mm（完整体素对角线）余量去除了大部分重叠，但 link3 仍约 0.057 mm、
右夹指约 0.381 mm，**该对照未通过**。

官方 `geometric_shapes` 的 `ConvexMesh::updateInternalData()` 按顶点到中心的径向扩张，
不是均匀法向偏置；`isPointInsidePlanes()` 也明确说明余量效果依赖方向。因此不能宣称
给定径向 padding 等于各表面的等厚包络。来源：
[官方 bodies.cpp](https://github.com/ros-planning/geometric_shapes/blob/ros2/src/bodies.cpp)。

诊断注意：MoveIt `fixed_frame_transforms` 序列化的 header 是源、child 是目标；转成 TF 广播
时交换名称而不取矩阵逆，并跳过自变换。隔离脚本初次误用已修正，生产相机外参未修改。

原始过程证据已归档到本文末节列出的 `tools/diagnostics/results/`；原临时目录可清理，
不作为正式配置或复现的必备输入。

### 真实目标边缘深度缓坡

排名修改已构建并整套部署。第 10、11 次正式请求均停在闭合规划，没有物理动作；
第 11 次唯一有 IK 的候选为 85。原生同场景 121 点闭合对照：有图 17 个无效、
离线无图对照 0 个无效。接触为 `<octomap> — link7_left`，首个深度 0.613 mm，
坐标 `[0.191107, 0.169660, 0.014660] m`，投回 RGB 像素约 `[493.1, 207.2]`。

同一 PointCloud2 用 ROS 官方解码器保留像素排列；RGB/深度剖面显示目标边缘是宽缓坡，
并非锐利实体边界。不能将这些凸起样本解释成刚性 Z=0 平面，也不能将推测当作独立实测。
已用原生 shape filter 做目标专用一层体素包络对照：过滤后恢复原始目标尺寸，
同一候选闭合由 **17/121 → 0/121**；总占用 17,150 → 17,060；
放置区 **707/707** 个体素坐标及大小逐项相同。地面、夹爪和环境碰撞检查不变。

正式修正仅在建图期间扩大目标过滤盒，每侧取同一 Octomap 分辨率（一层体素）；
收到对应滤波回调后同步恢复真实盒尺寸，再创建 MTC 任务。不是扩大实际附着物，
不是取消夹指—环境碰撞，也不是清空点云。运动节点从同一 launch 配置读取分辨率，
不另外写死毫米值。注意过滤回调时的诊断快照可能仍为临时包络，正式 MTC 起始场景必须为恢复后的尺寸。

修正已部署，MTC 与 move_group 运行参数均为 0.005 m。第 12 次新观测 138 候选无完整 IK，
未运动；这不能用来断言此前同候选闭合对照失效。既有原始采样预算提高到 4000（只改 `.env`，
默认仍为官方 200），增加可达姿态覆盖，不改候选位姿/评分门限。
进一步源码审查发现 ComputeIK 新建 SubTrajectory，不保留原生成器 creator；候选排序实现
必须显式转发接口属性。原生 MTC 类型回归 1/1 通过，整套重启后进入第 13 次实际动作。
